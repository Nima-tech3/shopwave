# 🛍️ Shopwave

## 📖 About The Project

ShopWave is an online shopping platform designed to provide users
with a simple and convenient shopping experience.

### ✨ Features

List of the project featurs: 

- User authentication (Login & Register)
- Browse products
- Search and filter products
- Add products to cart
- Manage shopping cart

## 🚀 Getting Started

Follow these instructions to get a local copy of ShopWave up and running.


### Prerequisites

Make sure you have the following installed:

- Git
- Django
- sqlite3
- Tailwind
- And more (Will be updated later)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nima-tech3/shopwave.git

   sh shopwave/setup.sh



### 💻 Usage

After starting the development server, open your browser and visit:

http://127.0.0.1:8000/

You can now explore ShopWave, browse products, search for items, and manage your shopping cart.
